## 3. Methodology v2 checklist (credit in brackets)
1. Data integrity -> statistics -> economics -> forward cohort, in that order [INCEPTION/VLLM four-stage gates].
2. MC null re-runs the strategy's own exit rule from random entries; >=5 seeds; gate on the minimum [GHCopilot].
3. Day-clustered bootstrap for PF CI; state the percentile convention [GHCopilot].
4. Artifact gate: flag if wins > 2x distinct exit days [GHCopilot].
5. Report hard TP/SL exits separately from TIME_EXIT; report expired vs TP/SL counts [INCEPTION].
6. Always state family size N for Bonferroni/DSR (Grok uses N>=65) [OpenCode credit to Grok; GHCopilot].
7. n>=100 independent outcomes spanning >=3 months [GHCopilot/Kilo].
8. Month-over-month (and yearly) decay test [GHCopilot].
9. Compound returns; equity starts at 1.0; annualize by calendar time [GHCopilot + self-found].
10. Benchmark on the identical window; add Sortino, Calmar, Ulcer, up/down capture [GHCopilot/Zoo].
11. Backtest exactly the exits the dashboard emits [GHCopilot].
12. Quote numbers only from the output JSON; say-vs-do check every claim [OpenCode].
13. ZooCode 5-trait composite for funds; steadiness = inverse volatility, so smooth funds lag in bull markets [ZooCode].
14. Affordability sim with real minimums, whole units, RBC DI $9.95 (5% of a $200 buy) [Buffy].
15. US mutual funds (FOCPX/FCNTX/FNILX) are not buyable at RBC; use Canadian equivalents [Buffy/ZooCode/OpenCode].
16. Track survivorship explicitly (current-constituent universes flagged) [Zoo/GHCopilot].
17. Freshness: date-stamp every input; today's fees on past years is a caveat [GHCopilot/Zoo].
18. Only three labels; NFA on every note [OpenCode].
