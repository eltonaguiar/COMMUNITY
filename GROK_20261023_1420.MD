## B. How to tell a true winner: my ideal approach

| Metric | ELI5 and pass mark | Real value (Oct 23) | Technical definition |
|---|---|---|---|
| Data integrity | Is the scoreboard honest? Recompute every P/L from entry and exit prices. | 0 mismatches above 0.05pp in 3,500 /audit closes (Oct 23) | Recomputed (exit/entry-1)*sign vs stored pnl_pct; dedupe; check timestamps, resolver freshness |
| Fair benchmark | Race the plain index on the same days. | SPY same window 11.0-11.8%/yr | Buy-and-hold total return over the identical date range, currency and fill convention |
| n (independent outcomes) | Enough separate coin flips to tell luck from skill: 100+, over 3+ months. | alpha_engine n 39 over 9 days: fails | Count of non-overlapping trades or decision days; overlapping picks on one day count once |
| PF and PF CI-low | Dollars won per dollar lost: 1.5+, and the unlucky end of the range 1.2+. | MomentumEMA PF 1.90, CI-low 1.24 | Gross profit / gross loss; 2.5th percentile of a day-clustered bootstrap |
| MDD (daily mark-to-market) | Biggest fall of the account, counted every day incl. open trades: 20% max. | Sector top-3 -20.8% | min(equity/running max - 1), equity starting at 1.0 |
| MC with real exits | Start trades on random days but exit with the same rules; strategy must beat 95% of them. | BTC 200d beats only 9-13%: fails | Null distribution of the metric from random entries plus the strategy's own exit mask; 5 seeds, gate on min; higher = stronger |
| DSR + family size | Sharpe after punishing how many ideas were tried: above 0.95 with N stated. | 12-1 momentum 0.89 at N=65 | Bailey-Lopez de Prado deflated Sharpe with N trials, skew and kurtosis |
| 2x costs | Still works if trading costs double: PF 1.3+. | Sector top-3 still passes | Rerun with doubled commission and slippage |
| Concentration | No single symbol over 30% of results. | crypto_liquidity_wick 100% one symbol: fails | Share of trades or P/L from the top symbol |
| Both halves + monthly decay | Works in the first and second half and isn't fading month by month. | rs-breakout second half PF 0.94: fails | PF>1 in each chronological half; Spearman of monthly PF vs time |
| Hard vs soft exits | Count stops/targets separately from time-outs and forced closes. | /audit: 1,005 TP, 1,300 SL, 493 time, 672 forced | Exit-type breakdown; PF on hard exits only |
| Artifact detector | Too many wins on too few days means a batch-stamp bug. | alpha_engine 34 wins on 9 days: flagged | Flag if wins > 2x distinct exit days |
| Forward cohort | Write the rules down first, then watch new trades. | None exists yet | Sealed, timestamped, cost-inclusive paper cohort, reconciled to execution |
| Fees (funds) | Yearly fee eats return every year. | XEQT 0.20% vs RBF460 1.94% | MER; plus commissions and trailers |
| Factor alpha | Return left after style tilts are explained. | VPMCX 3.17%/yr, t 2.91 | FF5+momentum regression, Newey-West t, BH-adjusted |
| R² closet indexing | If a fund moves 97% like the index, you pay active fees for an index. | R² > 0.95 = closet indexer | R-squared of fund vs benchmark returns |
| Survivorship | Dead funds vanish from data and flatter the rest. | 29 current megacaps used | Include delisted/merged funds or state the bias |
| Access and entry barriers | Can you actually buy it in a Canadian account at this size? | Beutel Goodman $5,000 min: not at $1-2k | Broker availability, minimums, commissions, fractional, DRIP |
