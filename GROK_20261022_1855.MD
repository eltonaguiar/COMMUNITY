## 3. Diagnosis of direction
**Converging (keep):** fix measurement first (resolver, artifact detector, walk-forward); independent re-derivation by a second agent; one-position-at-a-time accounting; sealed forward paper.
**Wasted churn (stop):** (1) the certify → downgrade loop: 3 PROVEN labels in 16 minutes. (2) Hourly generators (Darwin, Mutation Lab, DNA Factory, ROOCODE, 100+ scanners) creating trials that nobody counts in DSR. (3) Agents re-auditing the same cohort with different gates. (4) Dashboards and badges pages built before any edge exists.
**Conflicts:** gate definitions (n≥10 vs n≥100); OpenCode's own doc says both PROVEN and "none proven"; Kimi proposes kills that conflict with the mutation-before-kill rule; the resolver fix is on main but the detector that should verify it isn't.
**Root problem:** there is no single source of truth for *what counts as a trade*, *what counts as a trial*, and *what the gate is*.

### Single source of truth (SSOT)
1. `audit/gates.yaml`: your gates, versioned. All harnesses import it; nothing else defines a threshold.
2. `audit/trial_ledger.csv`: every strategy × param × universe ever evaluated (append-only). This feeds DSR/PBO.
3. `audit/clean_trades.parquet`: built by one pipeline: re-resolve from bars (first-touch), dedupe, one-at-a-time, cost-applied, with a status reason for every exclusion.
4. `audit/verdicts.json`: written only by `tools/audit_scorecard.py`. The UI shows only these labels: MONEY-READY / CANDIDATE / FAIL.
5. `audit/forward/<strategy>/<sha256-of-rules>.jsonl`: sealed forward cohorts (GHCOPILOT's #752 format).

## 4. The audit framework (pass/fail checks)
Every check is PASS / FAIL / N/A, with a test. A FAIL in **D, L or R stops the strategy** (the evidence is invalid, not weak).

### D. Data integrity (all classes)
| ID | Check | Test / code hint |
|---|---|---|
| D1 | No sentinels | `assert not df[px].isin([0,999999.9999,-1]).any()`; also flag `abs(log(px/px.shift()))>0.5` |
| D2 | Fresh feed | `now - max(source_ts) <= 2*cron_interval`; fail if the cache is re-committed with an unchanged hash (copy-trader since 06-21) |
| D3 | Timestamps present, monotonic | `created_at.notna().all()` and `created_at <= entry_ts <= exit_ts` (mega_mutation fails) |
| D4 | No market-closed prints | for non-24/7 classes, the entry/exit ts must fall in exchange session (pandas_market_calendars); FX: no Sat prints (myfxbook fails) |
| D5 | Exclusions disclosed | each excluded row has a reason; `excluded/total` reported per class (tournament: 60% MISPRICED_ENTRY) |
| D6 | Provider cross-check | 1% random sample re-priced from a second source, with median abs diff < 0.2% |

**Per class:**
| Class | Extra checks |
|---|---|
| Stocks | split/dividend-adjusted bars (`auto_adjust` consistent between signal and resolution); delisted names in universe (point-in-time S&P/Russell members); session close 16:00 America/New_York; earnings-gap flag |
| ETFs | total return (dividends); leveraged/inverse decay handled; avoid closed/merged ETFs survivorship; NAV vs price premium for bond/intl ETFs |
| Crypto | 24/7 so define a UTC day cutoff explicitly; exchange-specific (Binance vs Bybit) prices; perp funding accrued every 8h; delisted pairs (LUNA, FTT) kept; wash-volume filter |
| Bonds | **total return, not price** (coupon accrual) for ETFs/futures; duration matched; yield-curve data point-in-time (no revised) |
| Commodities | continuous contract roll method stated (back-adjusted vs ratio); roll dates excluded from signals; contract month matches the price feed (HG=F Yahoo = front month); limit-up/down days |
| FX | rollover/swap applied for holds across 17:00 NY; weekend gap; quoted pip spread by session (Asia wider) |
| Mutual funds | **forward pricing**: an order placed before 4 PM ET fills at *that day's* NAV, after 4 PM at the next day's; the signal must use NAV(t-1) or earlier; front/back loads + 12b-1; short-term redemption fees (often 1–2% under 30–90 days); survivorship (merged/liquidated funds: CRSP or Morningstar dead-fund list); share class consistent |

### L. Leakage
| ID | Check | Test |
|---|---|---|
| L1 | Entry after signal bar | `entry_ts >= signal_bar_close_ts`; entry price = next bar open (not signal close) |
| L2 | No future features | shift every feature by ≥1 bar; unit test: perturb bar t+1 and assert signal(t) unchanged |
| L3 | Point-in-time universe | universe at date t from a membership table at t; fail if built from today's list |
| L4 | No revised data | macro/fundamental series as-first-reported (ALFRED vintages) |
| L5 | Params frozen before OOS | rule hash + commit date < OOS start; `git log --format=%cI -- rules.py` |
| L6 | Regime filters causal | VIX rotator: uses VIX close(t-1) (known bug) |

### R. Resolution
| ID | Check | Test |
|---|---|---|
| R1 | First-touch from bars | re-resolve each trade with 1m/5m bars from entry: first of SL/TP hit; compare to stored outcome; mismatch rate < 1% (copper fails) |
| R2 | Same-bar ambiguity | if both SL and TP fall in one bar, count it as **loss** (conservative); report the count |
| R3 | Short sign | `pnl_short = (entry-exit)/entry`; unit test on a falling price must be positive; equity shorts avg +9.9% → recompute |
| R4 | One-at-a-time / overlap | drop a new signal on a symbol while a position is open; report n_raw vs n_independent |
| R5 | Duplicates | unique (strategy, symbol, dir, entry_ts rounded 1m) |
| R6 | Batch-close stamps | `max rows per exit_ts minute <= 3` and wins ≤ 2× distinct exit dates (artifact gate) |
| R7 | No placeholder exits | `exit_px != 0` and `pnl != 0.0` unless the exit was genuinely flat; 999999.9999 removed |
| R8 | Complete history | no 3,500-row cap; count must equal DB count |

| FX majors | 1–2 pip spread retail + swap | broker spread pages |

### K. Kill / promote
- **Promote to MONEY-READY**: all D/L/R PASS + S1–S13 PASS + F1–F4 PASS + operator sign-off.
- **CANDIDATE**: D/L/R PASS, PF ≥ 1.3 net, CI-LB > 1.0, null ≥ 90th pct, sealed forward test running.
- **FAIL**: any D/L/R FAIL, or PF < 1.1 net, or CI-LB < 0.9, or forward PF < 1.0 after 50 trades.
- **Kill**: propose only. Mutation-before-kill (one pre-registered variant, counted in the ledger) → operator approves.
- Demotion is automatic if forward PF < 1.0 after 50 trades or MDD > 20%.

## 12. Critic checklist (how a skeptical quant tests each item in our data)
**Stats**
| Check | How to test it here |
|---|---|
| n independent | After dropping same-symbol overlaps (`scan.py` clean()), count rows; also distinct close days. |
| Independence | Cluster by close day. If days are under n/3, trades are clustered; use the day-bootstrap CI. |
| Confidence interval | Day-clustered bootstrap PF; gate CI-LB ≥1.2. |
| Null Monte Carlo | Same symbols and hold, random entry dates in the window, 1,000 runs; real PF ≥95th pct. |
| Permutation | Shuffle direction labels across trades within each day; p<0.05. |
| DSR / PBO | DSR with N = all trials in the family (count every genome mutation and leaderboard cell, not 1); CSCV PBO <0.2. Any DSR >1 is a bug. |
| Multiple-testing count | Count strategies in /audit leaderboard (1,025) plus pf_registry entries; Bonferroni/Holm the best p. |
| Regime / month stability | PF by calendar month; ≥70% months PF>1; no month >40% of profit (Kilocode Sept cell fails). |
| Concentration | Top-symbol share ≤30%, PF ex-top ≥1.3 (m017/m084: 100% one symbol, FAIL). |
| Capacity | Position size ÷ 20-day dollar volume ≤1%; square-root impact at 2× cost. |
| Turnover | Trades/day × cost; PF at 2× cost ≥1.3 (luxalgo LONG drops to 0.94: FAIL). |

**Technical**
| Check | How to test it here |
|---|---|
| Lookahead | Hold time under 2 min or closed_at ≈ created_at means the resolver saw the future (genome: 955 rows). |
| Signal-bar entry | Entry price must equal the next bar's open, not the signal bar's close; compare to bars. |
| Survivorship | Universe file dated at signal time; include delisted coins and dead funds. |
| Point-in-time universe | Universe at date t comes from a membership table dated t, never today's list (L3). |
| First-touch resolution | Re-resolve SL/TP from 1–5 minute bars; same-bar both touched = loss. |
| Short sign | Recompute (entry−exit)/entry and compare to stored pnl (scan does this: 45 mismatches). |
| Sentinels / placeholders | Reject 0, ≥999999 or ≤-999999 values in prices, exits and metrics. |
| Batch closes | ≥10 rows on one close timestamp means the resolver bulk-closed them (1,412 rows removed). |
| Asset-class labels | Infer from symbol (USDT, =X, =F, ETF list) and compare to the stored class (92 mislabels). |
| Costs / slippage / funding / borrow | 1× and 2× round-trip, perps funding every 8 h, short borrow for equities. |

**Fundamentals**
| Check | How to test it here |
|---|---|
| Factor alpha (stocks/ETFs) | Regress the daily strategy return on Fama-French 5 plus momentum (Ken French library); alpha t-stat >2 after costs. If beta explains the PnL, it isn't an edge. |
| Market beta (crypto) | Regress on the BTC daily return; long-only crypto in a rally isn't alpha. |
| Sector / earnings concentration | Share of PnL from one GICS sector, and from trades held across an earnings date; each ≤40%. |
| Funds | Expense ratio and loads netted out; alpha against the category benchmark (Morningstar category or a matched ETF); survivorship-free universe. |
| Bonds | Total return including coupon, duration-matched benchmark. |
